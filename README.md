# VQS - A Variant Query Standard for Beacon and beyond

The VQS project aims to provide a framework for genomic variation requests in
with reference to and in alignment and with standards - particularly [VRS](https://vrs.ga4gh.org/) and
[Cat-VRS](https://github.com/ga4gh/cat-vrs) - developed by the GA4GH VRS workstream under the general "Genomic
Knowledge Model (GKM)" umnbrella; but - probably - include additional parameters
related to "common use cases" which are not directly reflected in VRS standards
(e.g. genomic feature identifiers such as gene symbols).

At least initially VQS targets a well defined request vocabulary for a next
version (v3.n) of the GA4GH Beacon standard.
